# Contributing to Modulo a Farfalla

Modulo a Farfalla is built to make capable match analysis accessible to grassroots
football. Bug reports, documentation improvements and carefully scoped code
contributions are welcome.

## Before opening a pull request

- Read `README.md`, `docs/QUICKSTART.md` and `docs/MATCH_ANALYSIS_TUTORIAL.md`.
- Keep original match media immutable; do not add real club footage, personal
  data, credentials, model weights or generated caches.
- Keep AI output as suggestions requiring explicit human review.
- Include focused tests and describe what you actually ran.
- Do not add a dependency or bundled asset without documenting its licence.

## Licensing and contributions

The project is source-available under the community licence in `LICENSE`,
not an OSI-approved open-source licence. Before a contribution can be included
in a distribution that is separately licensed for commercial use, the
contributor and maintainer must sign a written contributor agreement covering
that specific contribution. A pull request alone does not grant commercial
relicensing rights. Until such an agreement exists, the contribution is not
included in a commercial licence granted by the maintainer.

Do not submit code you do not have the right to contribute.
